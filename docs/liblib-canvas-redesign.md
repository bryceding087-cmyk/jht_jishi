# Liblib 画布参考与建绘通改造

调研日期：2026-10-15。通过用户登录后的 LibTV / Liblib 实际画布观察桌面布局、添加节点菜单、节点选中状态、视频编辑区、素材入口与缩放菜单。没有提交付费生成任务。

## 参考界面的设计

- 画布铺满工作区，固定侧栏收进项目入口；项目入口位于左上角，工作流／故事板切换位于顶部。
- 底部中央使用独立的圆角工具条，排列添加节点、移动／抓手、素材、角色、历史和帮助入口；视图工具在左下角独立成组。
- 节点名称和媒体尺寸位于卡片外侧，媒体画面占据卡片主体；两侧圆形端口通过细曲线连接。
- 选中视频节点时，在节点附近展开参考素材、提示词、模型及生成参数；高级设置按需展开。
- 添加节点采用紧凑列表，节点类型与上传、历史资源分组；缩放菜单支持输入比例、适合屏幕及固定比例。
- 视觉基准采用中性灰：画布约 `#141414`，工具条 `#262626`，边界 `#363636`，白色主要按钮；常用工具尺寸约 32px，工具条约 50px 高、12px 圆角。

## 建绘通中的实现

| 区域 | 实现 |
| --- | --- |
| 画布框架 | 全屏画布、顶部悬浮项目栏、导航抽屉、底部中央工具条、独立 Agent 入口；新建为空白画布，提供开始创作入口 |
| 节点编辑 | 将已有编辑器复用为屏幕坐标下的悬浮编辑面板；编辑区跟随节点移动和平移缩放，并限制在视口内 |
| 生成参数 | 紧凑模型、画幅、分辨率、时长控件；参考缩略图、提示词和高级设置；复用现有生成与上游解析 |
| 节点菜单 | 五类素材、视频生成、角色库；上传素材、搜索节点、从生成历史添加视频 |
| 视图控制 | 5%–800% 缩放、适合屏幕、可点击小地图、连线显隐、24px 网格吸附 |
| 整理画布 | 根据有向连接分列，循环连接采用有界回退；布局写入现有自动保存 |
| 故事板 | 按画布坐标浏览图片、视频和脚本卡片；视频展示实际上游提示词；点击定位回工作流 |
| 统一视觉 | 节点标题、端口、连线、菜单、编辑器和常用业务页面使用中性灰配色与统一字体 |

主要源码：`public/canvas-workspace.js`、`public/canvas-workspace.css`、`public/platform-theme.css`。`public/app.js` 提供选择、渲染、视口、素材、任务和保存接入点；`public/index.html` 加载新界面文件。

改造使用建绘通自己的模型、接口、项目和素材数据。Liblib 平台中的片段重拍、智能去字幕、主体消除等专属生成服务不在本次实现范围中；界面没有为这些未接入的服务添加占位按钮。故事板目前是画布素材的浏览和定位视图。

## 节点内上传与生成（2026-10-16）

对照已登录 LibTV 图片节点的参考缩略图、提示词与底部模型参数布局，新增 `public/inline-node-media.js` / `.css`，将画布节点操作改成详情框内完成：

- 图片、道具、角色参考图：直接添加参考、上传参考、选择或上传当前素材、编辑提示词、切换模型、生成图片。生成结果自动入库并更新原节点，无需弹窗确认使用。
- 音频：音效／配音／音乐模式、描述、图片或音频参考、模型与输出设置在同一详情框内完成，结果自动绑定节点。
- 视频：参考图的素材列表在详情框内展开，沿用现有视频提示词与参数生成流程。
- 脚本：直接在节点下方展示分镜编辑、Excel 导入、资源准备与提示词合成；资源库选择在详情框内展开。AI 图片资源创建对应图片节点，通过节点内生成表单完成并回连脚本资源。
- 原生文件选择器只负责选择本地文件；不再先打开独立的上传或生成业务弹窗。素材库页面自身的创作工具保持原页面用途。
- 提示词、模型、参考、输出设置及任务编号随项目保存；查询失败可重查。任务在切换节点后继续查询，完成后不抢占其他节点的选择与输入焦点。已应用结果会保存标记，刷新时不会覆盖用户后续手动替换的文件。

测试通过隔离模型响应模拟排队和完成，实际调用本地上传／保存接口，验证自动绑定、参考上传、切换与刷新恢复；不调用真实付费生成服务。截图 `20-inline-image-composer.png`、`21-inline-audio-composer.png`、`22-inline-script-workflow.png` 位于验证输出目录。

## 端口悬停与连线复核（2026-10-16）

- 修复圆形端口透明命中区域继承旧版输入／输出提示框的背景、边框和内边距，导致悬停出现蓝色大圆的问题。透明命中区域改用独立伪元素，移除旧提示框伪元素；端口悬停时保持 20px 圆环、短加号和固定比例。
- 连线端点改为节点内容框本体的左右边缘中点，与外置加号按钮的位置无关。移除 SVG 箭头 marker，普通线宽减为 1.25px，激活线宽为 1.4px。
- 对照参考站实际连线：蓝色 `rgb(100,180,255)` 渐亮线段和 3s 循环。按用户后续截图复核，将宽光晕层全部移除，流动层与激活连线统一为 1.4px；改为单条长尾亮段（`pathLength=300`、亮段 135、间隔 165），沿线逐级变亮，不向线条外扩散。选中节点时，其直接关联的连线出现流动；单独悬停或选中连线同样出现。其他线保持静止；减少动态效果偏好下取消流动动画。
- 回归检查覆盖端口真实悬停后的尺寸与伪元素、所有已连接内容框的端点误差、无箭头、关联选择切换、单线悬停和减少动态效果。`24-edge-flow.gif` 为实际页面的连线动效录制。

## @ 素材引用与视频音频参考（2026-10-16）

- 新增 `asset-mentions.js` / `.css`，在 Agent 新对话、已有对话及画布文本／图片／音频／视频提示词、脚本镜头提示词中输入 `@` 展开分类素材列表。支持名称搜索、图片缩略图、音频／视频／文本／角色分类、上下键、回车／Tab 选择和 Esc 关闭；确认引用不会误发送 Agent 消息。
- 选择后插入可读的 `@素材名`，同时保存稳定的素材或节点 ID。Agent 将素材加入消息附件；画布视频创建真实参考连接，图片和音频生成器将其加入参考列表；上游文本中的素材引用会随视频输入解析，文本节点引用会展开文字内容。
- 视频前端解析器和后端保存图解析器均支持音频节点，参考列表以音频图标显示。删除直接引用会同步移除 token、元数据和连接，不会刷新后重新出现。
- Ark 请求将音频编码为 `audio_url` 并使用 `role: reference_audio`，不会作为图片发送。模型校验在创建付费任务前完成：Seedance 2.0 系列需要同时有图片参考，音频最多 3 段、单段至少 2 秒、总长最多 15 秒；Seedance 2.5 支持仅音频参考，最多 10 段／总长 30 秒。格式限 WAV、MP3，单文件最多 15 MB。不支持音频参考的服务商／模型会给出明确错误，不会静默忽略音频。
- 依据火山方舟官方「创建视频生成任务」接口文档：<https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh>。部署端点别名可通过模型 `capabilities.audio_reference=true` 声明支持音频参考。
- 新增隔离后端合同检查，验证音频连线、正确请求类型、模型限制及文本引用去重；浏览器检查覆盖 Agent 新建及已有对话、画布 @ 音频搜索与回车选择、上游引用传递、视频直接引用及端口连接／移除。

根据用户提供的两张 LibTV 截图，将 Agent、画布和脚本提示词改为共享的行内引用编辑器。图片引用显示真实小图和“图片 N”，音频显示音符和“音频 N”；同一素材重复引用保持相同编号。视频编辑器的编号与实际参考排序一致，顶部参考卡统一为 60px 圆角缩略图，左上序号、音频左下时长，移除操作悬停显示。文本节点和脚本提示词也显示对应的参考缩略图条。
