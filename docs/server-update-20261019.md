# 建绘通累计更新补丁（media-library-styles-1）

本补丁适用于已安装 `video-reliability-1` 或 `market-task-return-1` 的现有 `jht-app` 容器，沿用之前的 `apply.sh` 安装方式。此前的集市登录和 HTTPS 代理修复须已安装。补丁包含截至本次 Git 提交的运行代码及静态资源，具体提交编号、文件哈希记录在包内 `UPDATE-MANIFEST.json`。

## 本次更新

- 返回集市后恢复正在生成的任务；视频下载失败时可重试原文件，不重复提交生成。
- 生成及导入内容进入「生成历史」，手动保存后才进入「资产库」。移出资产库保留历史及文件；各生成入口同步收藏状态。
- 视频生成状态和按钮锁定修复；画布与对话共用播放器，竖屏全屏完整显示，单击播放／暂停，双击退出全屏。
- 生成图片名称简化，避免把长参考文件名和 `@` 符号带入名称。
- 视觉风格扩展至 152 种，附完整参考缩略图及提示词。
- 生成历史／资产库、媒体分类切换加入滑块动效；更新再次生成图标；首页标签顺序调整为图片、视频、音频、Agent。

本地模型网关默认 `https://aimarket.hncig.cn:4090`，容器默认 `http://192.168.241.202:4091`，服务器显式配置继续优先。包内不含 `.env`、密钥、数据库、用户上传文件或本地运行环境，不修改服务器配置，也不更改数据库表结构。无需下载新依赖或导入新 Docker 镜像。

## 上传和安装

将以下两个文件上传至服务器 `/tmp`：

- `jht-media-library-styles-20261019.tar.gz`
- `jht-media-library-styles-20261019.tar.gz.sha256`

安装会重启 `jht-app`。请先等当前生成任务结束，再逐条执行：

```bash
cd /tmp
sha256sum -c jht-media-library-styles-20261019.tar.gz.sha256
tar -xzf jht-media-library-styles-20261019.tar.gz
cd /tmp/jht-media-library-styles-20261019
bash apply.sh
```

脚本先检查包内哈希及旧文件版本，再备份并更新代码，重启容器后检查健康、集市入口、静态资源和风格文件。发现未知版本时会停止，不覆盖未知修改。重复安装同一补丁会报告 `ALREADY APPLIED`。

成功后重新打开集市里的建绘通，必要时使用 `Ctrl+F5` 刷新。旧素材仍可在生成历史中找到；需要加入资产库的内容请手动保存。

## 回滚

```bash
cd /tmp/jht-media-library-styles-20261019
bash apply.sh rollback
```

代码备份保存在容器 `/app/.deployment-patches/media-library-styles-1/originals.json`。回滚恢复安装前的代码，保留业务数据；若安装后又改过这些代码，回滚会停止以避免覆盖后续修改。

补丁写入当前容器，重启同一容器后保留。删除容器并用旧镜像重建会回到旧代码；后续应使用本次 Git 代码重新构建镜像。
