## 本次更新

- 视频并发改为每个账号最多 10 个、全系统合计最多 100 个；超出后排队等待。跨项目、对话、Agent 和模型累计统计。原共享 API Key 的 5 个任务限制移除；已提交和结果待确认的任务继续占用名额。
- 新增管理员「系统日志」页面，包含用户操作、账号信息、生成请求和任务队列；支持用户、时间、任务类型和状态筛选，编号搜索、分页和自动刷新。
- 任务详情展示生成参数、本地请求编号、供应商任务 ID、错误、队列状态变化及关联操作。普通账号不能访问日志接口。
- 操作和状态日志从功能启用后开始记录，已有生成任务可直接查询。日志保存在现有数据库中，不需要新增数据库表。
- 包含当前工作区的累计创作、画布、模型网关及播放修复；所有运行文件与包内清单中的源码快照一致。

源码包不包含 `.env`、实际密钥、数据库、用户素材或开发机依赖。更新保留服务器现有账号、项目、模型配置、环境变量和素材。

## 上传与安装

上传以下两个文件到服务器 `/tmp`：

- `jht-admin-logs-update-20261029.tar.gz`
- `jht-admin-logs-update-20261029.tar.gz.sha256`

安装会重启 `jht-app`，请在当前生成任务结束后执行。使用已有的容器管理账号，在服务器终端运行：

```bash
cd /tmp
sha256sum -c jht-admin-logs-update-20261029.tar.gz.sha256 && \
tar -xzf jht-admin-logs-update-20261029.tar.gz && \
bash /tmp/jht-admin-logs-update-20261029/apply.sh
```

安装器先校验包内容和旧代码，保存安装前的代码备份，再更新和重启。随后检查健康接口、集市入口、HTTPS 来源、运行文件及静态资源哈希、视频并发上限和日志接口认证。检查不会提交真实模型请求。重复安装会报告 `ALREADY APPLIED`。

成功后重新打开建绘通，必要时按 `Ctrl+F5`。使用独立管理员账号登录，可在左侧看到「系统日志」。普通集市成员看不到此入口。日志功能说明见 `docs/admin-logs.md`，队列规则见 `docs/generation-queue.md`。

模型网关沿用服务器实际部署配置；标准服务器网关为 `http://192.168.241.202:4091`。安装包不修改运行环境变量。全系统 100 个视频名额是应用调度上限，上游模型服务自身的限额仍按其实际配置执行。

## 回滚

```bash
bash /tmp/jht-admin-logs-update-20261029/apply.sh rollback
```

备份位置：`/app/.deployment-patches/admin-logs-update-20261029-1/originals.json`。回滚恢复安装前的代码，业务数据及已记录的日志保留。如果更新后又修改了代码，回滚会停止以避免覆盖后续改动。

如重启检查未通过，查看：

```bash
jht-docker logs --tail 80 jht-app
```

本补丁写入当前容器。重启同一容器仍有效；删除容器并用旧镜像重建时，需重新安装补丁或改用包含新源码的镜像。
