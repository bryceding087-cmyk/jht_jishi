# 页面加载状态

统一图标为 `public/triangle-flow.svg`，采用提供的三色圆角三角流线动效，2 秒循环，支持系统“减少动态效果”。登录按钮内联同一 SVG，使未登录时也能显示，不依赖受认证保护的静态资源。

## 覆盖入口

- 登录提交、系统首次启动和启动失败重试。
- 打开画布、切换历史对话、读取 Agent 创作记录。
- 素材选择器与其读取失败重试。
- 模型管理的读取、刷新与保存状态。
- 图片、音频生成窗口的模型与素材初始化；图片任务提交和等待结果。
- 首页创作输入框的模型列表读取。
- 经由 `app.js` 中 `api` 发出的其他前台请求，提供统一的非阻塞请求状态提示。

## 交互规则

列表刷新保留旧内容；首次加载不显示“暂无数据”，只有成功返回空集合后才显示空状态。项目和资产加载失败会显示错误与重试入口。资产请求使用序号忽略过期响应，避免并发刷新时较旧的数据覆盖较新的结果。

项目列表（含回收站）和资产页面不显示列表转圈或“正在加载素材”提示，也不触发全局请求提示。读取期间通过区域的 `aria-busy` 表达忙碌状态。封面和素材媒体使用 `viewport-media.js`：初始只保留 `data-media-src`，`IntersectionObserver` 确认元素进入实际可视区域后才设置 `src`；不预取下一屏。视频和音频的元数据也仅在卡片可见时读取。首页最近画布使用相同机制，隐藏的首页内容不会提前加载封面。筛选、排序和刷新后重新观察当前卡片。

导航遮罩和通用请求提示延迟 200ms 出现，快速请求不闪烁；通用请求提示出现后至少保留 250ms。多个并发请求全部结束后才清除通用提示。导航遮罩按作用区域计数，成功或失败都在 finally 中移除并恢复 aria-busy。背景任务轮询不触发通用提示，使用各自已有的生成进度。

## 后续开发

加载样式位于 `public/loading-state.css`。新页面沿用 `api` 即可自动获得请求提示；数据区域可使用 `loadingMarkup(label, compact)` 显示统一图标与说明。需要等待后再切换内容的导航使用 `withLoading(task, label, target)`，默认覆盖主内容区域，不改变画布视角。任务进度应使用独立的业务状态，避免把轮询当作新页面加载。

项目和资产页面的列表读取使用 `api(url, {background: true})`，该选项只控制提示显示，不传给 `fetch`，也不屏蔽接口错误。上传、保存和生成等业务操作继续保留各自的反馈。

验证：Node 20+ 运行 `node tests/verify_loading_states.cjs`，使用独立临时数据库，模拟慢请求、失败、重试、快速请求和并发请求，不调用模型服务。可通过 PLAYWRIGHT_MODULE、BROWSER_CHANNEL、PYTHON 配置浏览器与运行时。
