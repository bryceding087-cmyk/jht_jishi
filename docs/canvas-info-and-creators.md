# 画布信息、创作者记录与媒体懒加载

项目卡片的更多菜单新增“画布信息”。弹窗沿用 `showModal` 与 `modal-motion.js`，显示所有者、创建时间、最新修改时间，以及全部节点、图片、视频、音频、文本、时间线、主体、其他的数量。

## 数据保存

- 项目原本已保存 `created_at`、`updated_at` 和节点图。`GET /api/projects/{id}/info` 从最新保存的节点图计算分类数量，避免重复保存计数后出现不同步。
- 新项目、资产和生成任务保存 `creator_id`、`creator_name`、`creator_username`。这些字段来自认证后的登录账号；请求中伪造的创作者字段不被创建接口采纳。
- 保存现有记录时保留最初的创作者，管理员代为重命名、编辑或保存生成视频不会改变归属。普通用户只能访问自己的记录，详见 [用户隔离说明](user-isolation.md)。复制项目属于执行复制的账号。
- 图片、音频后台任务及视频稍后保存，使用原任务的创作者；Agent 工作线程（含恢复运行）从持久化任务恢复创建身份，最终合成资产也保留该身份。
- 旧数据存在可靠的任务创作者或旧所有者账号时可解析显示；无法追溯的历史项目和资产继续显示“未记录”，不会改记成当前浏览者或共享画布所有者。
- 字段保存于现有 SQLite JSON 记录中，无需变更表结构或删除旧数据。

节点分类中 `prompt/text/script` 计入文本，`image/prop` 计入图片，`video/video-asset` 计入视频，`character/subject` 计入主体。通用 `asset` 节点按关联素材类型分类，未关联素材的图片占位节点计入图片。无法识别的节点计入其他。

## 页面加载

项目和资产页面不再显示列表加载动画。媒体只在进入可视区域时设置 URL，视频、音频元数据同样延迟读取。搜索、分类、排序与重新加载后重新观察当前卡片。请求失败仍保留已有内容并提供重试入口。详见 [加载状态说明](loading-states.md)。

浏览器原生图片、链接和选中文字的拖动预览在应用页和登录页禁用；画布已有的指针拖动交互继续工作。
