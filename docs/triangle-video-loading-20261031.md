# 视频加载仅保留彩色三角形

版本：`triangle-video-loading-20261031-1`。

资产预览原先在彩色三角形蒙层下仍启用浏览器原生视频控件，原生加载圆环会透出，出现两个加载动画。现在视频首帧就绪前关闭原生控件，加载完成后恢复播放控件；重新加载同样使用这条流程。增加 Chromium 原生加载面板隐藏样式。对话播放器的旧圆环也替换为同一彩色三角形，错误与重试提示保留。

真实 Chrome 验证了慢速资产视频只有一个三角形、加载后恢复控件；播放器现有浏览器回归覆盖慢加载、加载失败、重试、正常播放、全屏、不同画幅和减少动态效果。

## 服务器安装

累计包含前面的轮询闪烁修复、Wan 3.0 接入、视频回调与文件恢复更新。将包与校验文件上传 `/tmp`，待生成任务结束后执行：

```bash
cd /tmp
sha256sum -c jht-triangle-video-loading-20261031.tar.gz.sha256
tar -xzf jht-triangle-video-loading-20261031.tar.gz
bash /tmp/jht-triangle-video-loading-20261031/apply.sh
```

安装后重新载入集市内的建绘通页面。安装器校验版本并备份源码，保留环境文件、密钥与用户素材，服务器模型网关仍为 `http://192.168.241.202:4091`。

回滚：`bash /tmp/jht-triangle-video-loading-20261031/apply.sh rollback`。源码回滚保留业务数据；若回滚到未接入 Wan 的版本，请勿选择数据库中保留的 Wan 模型。
