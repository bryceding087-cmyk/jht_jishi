# 视觉风格选择

首页图片／视频创作、Agent 输入工具栏、画布图片／视频节点和图片生成窗口提供「风格」入口。选择器支持名称和别名搜索、全部／真人／2D／3D 分类、参照图卡片、无风格和自定义风格提示词。音频生成不附加视觉配方。

风格弹出框复用现有参数弹窗的视觉与进出动效。默认按钮显示四角星；选中预设后，用该风格的参照图缩略图替换图标，先收缩 120ms 再弹出 280ms。自定义使用编辑图标，清除后恢复四角星；减少动态效果设置下直接切换。内部鼠标焦点变化不会关闭弹出框，点击外部、Escape 或 Tab 移出时关闭。

本地目录来自用户提供的 visual-style-studio 1.0.0：真人 16 种、2D 13 种、3D 11 种。`resources/visual-styles.json` 保存中英正式配方、别名、美术避免项、视频运动与一致性建议、来源链接。`public/style-previews/` 保存按技能包 manifest 指定版本导出的 40 张 JPEG 缩略图，原始文件与网页缩略图分别记录 SHA-256。网站不依赖桌面技能包路径。

参照图只供选风格，不自动作为人物或场景参考上传。模型请求只使用正式的 `image_style_prompt_zh` 配方，不包含 `preview_subject` 或示例画面提示词。

## 请求与保存

登录后通过 `GET /api/visual-styles` 读取卡片目录。图片、视频请求与 Agent 偏好接受以下字段：

```json
{"visual_style": {"id": "feature-animation"}}
```

自定义使用 `{"id":"custom","custom_prompt":"纸雕材质，柔和侧光"}`，最长 1500 字。传 `null` 或省略字段不附加风格。服务端校验 ID，拒绝客户端替换预设配方。

每个生成任务保留原始 `prompt`、`visual_style`、包含配方和目录版本的 `style_snapshot` 以及实际发送的 `effective_prompt`，随现有任务记录保存到 PostgreSQL。画布设置和 Agent 偏好也保存选择。历史对话恢复和再次生成使用该轮的选择，清除风格不会继承首轮设置。新字段使用现有任务 JSONB，不需要修改数据库结构。

后台在图片与视频提交供应商之前统一组装提示词，支持现有 Ark 和 MiniMax 视频适配器。内容与风格合计超过 4000 字时在提交前报错，不静默截断。再次生成从原始描述重新组合，避免重复追加风格。

用户指定背景、光线、色彩或构图时，服务端按关键词去除预设中对应维度的默认短句；用户指定运镜时不追加预设运动建议。这是保守的文本规则，不是完整的语义冲突检测；最终画面仍受模型对提示词的理解影响。自定义配方按原文发送。Agent 的导演步骤会收到正式风格配方，图片和视频工具调用也继续携带选择；制作参数卡不再用旧的三个风格选项覆盖它。

## 验证

`test_visual_styles.py` 覆盖目录与图片完整性、选择校验、冲突适配、真实 ASGI 保存／清除／重试与权限隔离。图片 worker 和视频适配器测试检查实际供应商请求，Agent 测试检查选择经过确认流程后传入生成工具。`visual_style_picker.test.mjs` 在内存 DOM 中验证分类、搜索、预设、自定义、清除和关闭交互。测试使用临时数据及替代供应商响应，不调用付费生成接口；DOM 测试不替代浏览器视觉验收。
