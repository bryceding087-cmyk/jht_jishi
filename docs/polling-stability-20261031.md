# 生成历史与画布轮询闪烁修复

版本：`polling-stability-20261031-1`。

原因已定位到前端刷新方式：生成历史在存在待保存视频时每 3 秒刷新一次，原实现会在请求开始和结束两次重绘，并用 `innerHTML` 替换全部日期分组和素材卡片。图片、视频因此反复重新创建，视频预览会被停止并从头加载。资产刷新还会无条件重绘画布、重新加载节点设置；画布任务轮询会无条件替换状态文字容器。

本次保留轮询频率和任务进度更新，改变 DOM 更新方式：

- 生成历史按素材 ID 复用卡片和日期分组；素材地址、类型未变时保留媒体元素。状态、名称和选择变化只更新对应内容。
- 后台刷新开始时保留现有内容；请求出错后仍展示重试入口。
- 悬停预览的监听只绑定一次，连续刷新不会主动停止播放或重置播放位置。
- 画布轮询保留状态文字容器和未变化的预览。只有素材实际改变时才重新同步画布和设置面板。
- 任务轮询和自动历史刷新使用后台请求，不弹出页面加载提示。入口版本号已更新以刷新浏览器缓存。

## 安装服务器更新

这是累计更新包，包含此前视频回调、视频文件恢复和 AI 集市 Wan 3.0 接入。服务器模型网关沿用 `http://192.168.241.202:4091`，不写入密钥、不修改部署环境文件。

支持源码基线、账号模型更新、视频回调 v1/v2、视频文件恢复和 Wan 3.0 更新版。写入前校验所有文件，遇到未知源码修改会停止。等待现有生成任务结束，将压缩包和外部校验文件上传 `/tmp`：

```bash
cd /tmp
sha256sum -c jht-polling-stability-20261031.tar.gz.sha256
tar -xzf jht-polling-stability-20261031.tar.gz
bash /tmp/jht-polling-stability-20261031/apply.sh
```

安装后刷新集市内的建绘通页面，已打开的旧页面需要重新载入前端代码。

回滚源码：

```bash
bash /tmp/jht-polling-stability-20261031/apply.sh rollback
```

源码回滚保留数据库与用户素材。如果回滚到未接入 Wan 3.0 的旧版本，共享 Wan 配置记录仍在数据库中，请勿在旧代码选择该模型。
