# 建绘通 Agent 与幕间剧本工作台

首页的 **Agent** 入口支持普通问答、单独生图、单独生视频、剧本创作和一句话短剧。页面沿用建绘通的深色背景、紫色强调色、现有输入框和画布组件。剧本工作台参考小云雀的目录／稿件／对话布局；剧本阶段与实际素材依赖采用幕间方案。

## 使用流程

画布右侧 Agent 每轮从服务端读取当前画布名称、版本、节点文本、连线、分组、素材元数据和生成状态，并结合当前选中节点或分组回答。发消息前先保存画布中的待保存修改。Agent 创建的画布仍沿用原始创作会话；手动创建的画布各自绑定独立会话，空画布也能识别项目名称。

「技能」菜单与模型收到的能力清单一致：画布理解、画布操作、剧本创作、资产与分镜拆解、图片与视频生成、制作画布与成片。画布理解读取已有文本和素材元数据，不代表已分析图片像素或视频画面。大画布优先提供选中内容并标记省略的明细，节点总数和类型统计仍覆盖全部画布。

画布操作通过服务端工具执行，画布 ID 只取已绑定的会话，模型不能指定其他项目、调用任意接口或执行脚本。支持节点增改删、移动、复制、连线、分组、排版、绑定当前素材、节点生成与排队取消，以及最近 Agent 编辑的撤销/重做。视图桥接支持选择、适合屏幕、缩放、平移、网格吸附、连线显示、小地图、工作流/故事板、当前画布素材/生成状态与节点已有工具。模型配置、账户及其他画布不在权限内。只有用户在本条消息明确提供的素材才可作为额外引用。

同一批图形修改先完整校验，再以画布版本和操作回执一同提交；无效节点或版本冲突不会部分覆盖画布。重复消息和恢复使用回执，节点生成沿用现有幂等请求与用户任务队列。撤销只影响画布编辑，不能撤销已经发给供应商的生成；取消只适用于尚未提交的排队任务。历史消息重新显示不会重复执行旧的缩放、面板或生成命令。

1. 进入首页 Agent，选择「自动识别」，直接输入问题或创作要求。也可以选择「生成图片」「生成视频」「剧本创作」「一句话短剧」。一般问答不创建剧本、画布或媒体任务。
2. 剧本任务显示左侧目录、中间稿件和右侧助手。按「故事设定 → 分集大纲 → 剧本正文」逐步写作，已完成稿件可先阅读。可以只写设定、只写到某一集，或完整创作。
3. 可向助手提出修改，也可点击「编辑」直接改稿。保存为新版本，旧版本可以查看、下载、恢复为新版本。上游改动会标记下游待同步；不会覆盖用户正在编辑的内容。
4. 「一句话短剧」完成剧本后，拆解角色、场景、道具和逐镜提示词，批量应用创作技能优化图片与视频节点，再创建真实制作画布。「制作与成片」直接展示故事板，按人物、场景、道具、视频、音频、图片、成片、文稿分类浏览。点击卡片进入对应节点，上方滑动开关在故事板与画布之间切换，并保留当前对话未发送的草稿。拆解与优化期间显示实际进度，中断后可复用已完成步骤。仅写剧本时，可在此点击「创建故事板」。
5. 通过输入框下方的参数按钮设置画幅、目标时长与视觉风格。新任务使用「模型管理」中的默认模型；已有任务保留其模型选择，已有画布的模型与参数以各节点为准，可在节点中独立修改。
6. 在画布逐项生成，或返回「制作与成片」点击 **制作成片**。连续制作先生成缺失的人物、场景和必要道具，再由视频节点直接引用这些素材生成镜头，最后合成分集和整剧。已完成且有效的输出直接复用；媒体生成按所选供应商实际调用计费。

例如：「回答我什么是景别」「生成一张雨夜古城的图片」「生成一段猫咪转头的视频」「先写一个悬疑短剧的故事设定」「用一句话创建两集短剧：失踪十年的父亲突然出现在家门口」。

「自动识别」与画幅、时长共用深灰圆角参数弹窗。切换任务类型、参数、工作台目录和剧本阶段时，选中标记连续滑动；系统设置减少动态效果时直接切换。目录与页签保留在页面中，后台进度更新不会重置正在阅读的稿件滚动位置。工作台移除了底部标语、顶部「创作偏好」入口和右侧输入框的「技能」按钮。

对话中的执行步骤与过程说明按轮次归入默认折叠的「处理详情」，只显示简短状态和完成数量；展开后可滚动查看记录，后台更新保留当前展开状态。正文、生成结果和错误处理入口直接呈现。图片、视频、音频及 Agent 对话页移除顶部图标和助手标题，正文使用原标题所占空间。

拖动右侧对话栏左边缘可调整宽度，松开后记住当前账号的设置；双击边缘恢复默认。聚焦分隔条后也可用左右方向键调整宽度，Home／End 切到当前窗口允许的最窄／最宽。窄屏仍采用原有上下布局。

## 画布与素材

- 画布左侧按人物身份归组，同一人物的造型变体放在一起；必要道具单独成组。中间按场景归组，包含该场景的参考图与变体。右侧按集排列视频片段，每集的剧本与剪辑节点放在旁边，整剧有独立的最终合成节点。导入或添加的音频节点归入“声音素材”，已有手动分组保持不变。
- 一个视频节点是一段模型生成片段，可以包含多个分镜。同一原文场次、同一场景的连续分镜按所选模型最大时长、参考图数量与提示词容量组合。MiniMax H3 明确支持片段内切镜，普通 `cutBefore` 不再强制另建节点：5 秒和 6 秒的连续分镜可合成一个 11 秒节点，提示词按 0–5 秒、5–11 秒分别描述动作、对白和机位。`generationBreakBefore`、人物造型冲突和场景变化仍会拆分；未确认片段内切镜能力的模型保留原有 `cutBefore` 边界。分镜可使用小数秒，片段使用模型支持的最小足够时长，不足部分明确写作收尾停留，完整保留分镜顺序、动作和对白。缺少模型时长能力时保守使用单分镜，不猜测更长时长；超过上限的单镜必须先拆分。
- Agent 制作画布中的视频直接引用人物、场景和必要道具素材，不再自动创建首帧或尾帧图片节点。节点保存原文场次、行号和引用说明，可追溯到剧本。原生画布中用户手动选择的首帧、首尾帧和纯文本功能继续保留。
- 定义编号只用于识别角色／场景等。生成请求必须解析到已完成、当前账号可访问的真实素材；缺图、断线、删除、类型不匹配或待核对时拒绝提交。
- 视频与合成节点隐藏依赖连线，生成调度仍保留真实引用关系。详情页通过 @ 选择画布中的图片、角色和场景，即使尚未出图也会显示名称与“待生成”标签；素材生成后引用解析到该节点最新结果。移除引用同步移除标签与依赖，循环引用会被拒绝。旧画布的数字图片引用也显示为标签，无需改写正在运行任务的提示词。
- 提交前把命名引用编译为当前真实输入的图片／视频／音频编号；原始草稿与请求幂等标识保持稳定。手动连接与上传的参考同样参与生成。任务结束时核对节点内容与引用，避免把旧结果覆盖到新方案上；冲突结果保留在生成历史。
- 同步剧本到画布保留手动节点、布局、参数和分组。变化的生成方案显示待核对，可选择采用更新方案或保留当前方案。被移除的原节点保留并标记过期。
- 旧视频改为直接引用时，已生成或手动修改的方案保留原提示词和原依赖，等待用户核对。采用更新方案会同时更新素材引用、提示词标签、生成模式与连线，旧成品保留在历史中，下游合成标记待更新；用户手动连线保留，不再使用的自动首尾帧归档。
- 全部生成内容进入生成历史，只有手动保存才进入资产库。

容量为 1600 个节点、10000 条连线、100 个分组、每组 400 个节点。超限会提示拆分项目，不静默删集或删镜头。超过 250 个节点时，页面仅挂载视口附近和选中节点，全部数据仍持久保存。

节点提示词优化采用 Seedance 提示词专家、漫剧全流程、AIPDD 影视工具等五项 SkillHub 技能的建绘通适配规则。原文与引用保持不变，文本模型只补充执行指导，手动编辑通过更新方案保护。一次请求批量优化最多 6 个节点，最多同时运行 3 批；每个节点仍有独立的上下文、校验和缓存，相同输入同步时直接复用已有优化。来源版本、选择依据、适配范围及验证说明见 [SkillHub 创作技能接入](skillhub-creative-skills.md)。

拆解先统一角色、场景、道具目录，再按原文场次并行安排镜头，最多同时处理 3 个任务，完成一个便补入下一个。场次任务使用统一的资产编号和原文行号，结果按剧本顺序合并，并检查场次、对白和引用覆盖；已完成的有效拆解与节点优化可以继续复用。格式或引用校验未通过时只修正对应任务，重试不会要求重写已经完成的剧本。明确且唯一的资产别名由程序归一化，无法确定的引用会说明场次、字段及编号，不通过删除引用来继续生成。

同一角色的新服装或状态使用独立资产编号；`reuseId` 指向基础角色时，不会把新变体的定义覆盖到旧造型，也不会丢失镜头引用的新编号。恢复旧任务时，先用修正后的规则在本地重新校验已经收到的失败结果，能够恢复的结果直接复用；原文未变且已完成的集不重新拆解。

模型返回的明确行号格式（如 `45`、`45-45`、`45–46`、全角数字或两端行号数组）在本地转换为统一坐标，并验证整段都位于指定原文场次。对白列表转换为文本时保留说话人、原台词及画外音标记，原始结构一同保存；对白覆盖检查仍然执行。格式差异不再直接打断制作。旧提示词版本的已收到场次回执也按原剧本、模型、风格与资产目录核对后复用，未知结果的请求不因版本升级而自动重发。

拆镜回复附带的已登记素材编号列表，或仅含编号、名称、类型、造型与使用镜号的清单，按冻结目录中的引用核验，不再误当作需要重新提供原文行号的新素材定义。未知编号、身份或造型冲突仍会拒绝；真实素材定义与每个镜头仍需通过原文来源及对白检查。恢复格式错误时优先核验最后收到的修正回复，保留其他已完成场次；存在结果未知的请求时不自动复用较早回复跳过核对。

制作页展示当前的资产准备、场次拆解或提示词优化阶段，以及已完成、运行中、排队和需处理的数量。批量提示词优化分别显示节点数量与批次数量，并明确“最多并发 3 批、每批最多 6 个节点”；阶段耗时和修正次数显示在同一进度卡。已完成节点数以结果保存为准，完成阶段不再显示陈旧的运行或排队数量。暂停与阻塞会保留已完成进度并显示对应状态。旧任务缺少并发统计时只展示已有进度，不推算运行数量。

## 任务与兼容性

新建 Agent 使用 `studio-v1`，复用宿主的文本模型、媒体任务、用户权限、操作回执、暂停与恢复机制。切换页面或关闭页面不会终止服务端任务，重新进入原对话可继续查看。暂停会停止提交后续步骤，已经发出的供应商请求可能继续完成。

服务重启后，Agent 按宿主恢复规则保留稿件、任务与操作回执。对于调用结果未知的请求，不自动重复提交；界面提供继续查询或明确重试。单独的剪辑任务若被服务重启中断会显示中断状态，允许重新合成。运行仍要求单个 Uvicorn worker。

原有分阶段视频 Agent 保留；旧 run 继续由原引擎处理。调用 `/api/agent/runs` 时传 `workflow: "video"` 可使用旧流程，新入口显式传 `workflow: "studio"`。

## 接口与文件

| 接口 | 用途 |
| --- | --- |
| `POST /api/agent/runs` | 新建任务，`workflow`、`intent_hint` 选择流程 |
| `GET /api/agent/runs/{id}` | 对话、任务、稿件和制作状态快照 |
| `POST /api/agent/runs/{id}/messages` | 对话；暂停、恢复、重试；`studio_canvas` 创建／同步画布；`studio_generate` 连续制作 |

| `POST /api/studio/renders` | 按项目、节点和画布 revision 创建持久化合成任务 |
| `GET /api/studio/renders?project_id=...` | 查看当前项目合成任务 |
| `GET /api/studio/renders/{id}` | 合成进度与结果 |
| `POST /api/studio/renders/{id}/cancel` | 取消待执行或正在合成的任务 |

主控：`agent_studio.py`；画布协议与回填：`studio_graph.py`；合成任务：`studio_render.py`、`studio_render_adapter.py`；界面：`public/agent-studio.*`、`public/studio-canvas.*`、`public/studio-contract.js`。无需独立 Node 服务或另一套数据库。

工作流来源为用户提供的幕间项目 `script-agent/integrations/jht`，以及本地 `my-script-agent`、`script-assets` 的工作流与输出契约。必要参考已随代码存放在 `agents/script-studio/`，运行不依赖开发机上的外部路径。使用现有 Python 依赖、FFmpeg 与 Docker 文件复制规则。

## 千问 Responses 接口

千问示例 `client.responses.create()` 对应模型配置：Base URL 为 `https://maas.qianwenaiapi.com/compatible-mode/v1`，API 路径为 `/responses`，模型 ID 为 `qwen3.8-max-0902`。模型管理的思考模式可设为「启用」，请求会传 `enable_thinking: true`；「由模型决定」则不传此服务商扩展参数。原有 Chat Completions 模型继续使用 `/chat/completions`。

文本模型的「请求超时（秒）」可在模型管理中编辑，范围为 5～900 秒，通用默认值为 300 秒。千问开启思考模式并生成长剧本时，单集可能超过 5 分钟，建议设为 900 秒。设置按模型保存，后续请求（包括原任务未完成步骤的重试）读取最新值，不需新建对话。这里是单次等待响应的读取超时，不是整个多集创作任务的总时限；若仍超过设置值，任务会保留已完成稿件并停止后续提交。

读取超时表示未收到完整回答，无法据此判断服务商是否完成或计费。当前非流式调用未取得响应 ID 时，刷新和「继续查询」均不会重新提交此文本请求。核对服务商记录后，可在原对话点击「重新请求（可能再次计费）」；已完成的设定、大纲及剧本版本直接复用，只重新请求未完成的步骤。

Responses 使用 `input` 保留消息角色，读取 `output` 中 assistant message 的 `output_text`，忽略 reasoning／工具条目。模型返回失败、不完整正文或拒绝时，不将部分内容保存为完整稿件。协议依据用户提供的千问示例及 [OpenAI Responses 文档](https://developers.openai.com/api/docs/guides/text)。

部分本地 DNS 无法解析 `maas.qianwenaiapi.com`。`model_transport.py` 只对这个已知公网域名提供备用解析：本地解析失败时，通过带证书校验的阿里云 HTTPS DNS 获取有效公网地址，按 TTL 短暂缓存并直连；HTTP Host 与 TLS SNI 始终使用原域名。它不会修改系统 DNS、hosts 或其他模型地址，也不把 API Key 发送给 DNS 服务。恢复只发生在建立连接、发送模型请求之前，读取超时或未知结果不会自动重发。

遇到解析错误时会显示具体接口域名。修正连接后在原对话点击「重试失败步骤」，已完成故事设定与稿件版本继续复用。

## 当前合成边界与验证

分集合成支持 1–80 个镜头、最长 20 分钟，单个使用片段最长 60 秒；整剧支持最多 60 集、实际总时长不超过 2 小时。支持 16:9、9:16、1:1，保留视频原声；可修改镜头顺序、使用时长、静音。新剧本制作流程没有自动口型同步、额外配音／BGM 或精确字幕时间轴。旧视频 Agent 的配音与混音功能保持独立。

集数设置允许 1–60 集，但可实际生成的总规模同时受画布容量及上下文上限约束。当前一次写作上下文最多 18 万字符，超限会要求缩小范围，不裁切已有正文。文字模型必须支持结构化 JSON；不完整的稿件与引用会经过校验，已收到但无效的回答最多自动修正一次。

普通问答同样经过意图分流。已收到的普通文字、空回复、损坏的 JSON 或非对象结果会进入同一次格式修正机制，不直接作为回答或生成指令执行；连续两次不合格才停止并提示重试。首次无效回复与修正请求分别保存操作回执，恢复任务时复用已有回执。网络失败、读取超时及结果未知的请求不会因为格式修正而自动重发，已有稿件保持不变。

测试使用临时数据库和模拟供应商，不调用真实收费模型。`tests/test_agent_studio.py` 覆盖分流、实际素材引用、历史版本、权限、幂等、暂停恢复、语义失败重试、合成冲突及真实 FFmpeg 成片。`tests/agent_studio.browser.cjs` 覆盖真实认证下的工作台、窄屏导航、手动编辑、正在运行时离页恢复、画布跳转、账号隔离及 500 节点显示。实际供应商的文本质量、画面一致性和语音质量仍取决于所选模型。

故事板／画布滑动切换位于工作区顶部居中，不随故事板内容滚动；画布沿用相同黑灰开关。创作目录、稿件标题、分类、按钮、消息卡片与制作面板统一使用中性灰。停止请求立即隐藏思考提示，终止状态和历史恢复都会清理未闭合的路由步骤；停止失败时仍可恢复运行提示。
