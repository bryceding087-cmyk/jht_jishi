# 离开集市后恢复生成任务（market-task-return-1）

修复集市切换上方页签、销毁建绘通 iframe 后，再进入只显示空首页的问题。原来的生成任务已经保存在服务器，但新页面没有恢复当前对话，容易让用户重复提交并遇到上游视频并发 429。

## 返回行为

- 重新进入 `/market` 时，优先恢复当前账号正在生成的对话；有多个运行中的对话时，优先选择上次查看的一个，否则选择最近更新的一个。
- 同一浏览器页签记住上次查看的对话编号。任务在离开期间完成，返回时仍可显示原结果。浏览器禁用第三方存储时，仍从服务器发现当前账号正在执行的任务。
- 图片、视频、音频对话从服务器读取原任务并刷新状态；Agent 对话沿用已有的运行恢复能力。明确指定的对话、画布、首页或嵌入画布链接优先，不被自动恢复覆盖。
- 视频查询暂停或服务重启后，原用户的新集市会话可以恢复原供应商任务 ID 的 GET 查询。重新取得有效会话后立即恢复，不必等待旧授权失败的退避时间。
- 查询暂停仍占用当前对话的生成位置，避免误判为已结束后重复提交。不同对话仍保持独立。恢复不会自动重发生成 POST，也不会消除供应商实际存在的并发上限。

浏览器只保存按用户隔离的对话编号；任务、结果与权限以服务器为准，API Key 不写入浏览器或恢复记录。已删除的对话、其他用户的任务不会自动恢复。图片和音频的进程内请求在服务器重启后无法重新接续，页面会如实显示中断状态，不会自动重新收费生成。

## 服务器更新包

本次更新包适用于已安装 `video-reliability-1`（以及此前集市登录、HTTPS 代理修复）的 `jht-app`。包括本次恢复修复及本地/容器模型网关选择的依赖文件。容器入口默认保持 `http://192.168.241.202:4091`，本地启动默认使用 `https://aimarket.hncig.cn:4090`；服务器显式环境配置继续优先。

将以下文件上传到服务器 `/tmp`：

- `jht-market-task-return-20261019.tar.gz`
- `jht-market-task-return-20261019.tar.gz.sha256`

执行：

```bash
cd /tmp
sha256sum -c jht-market-task-return-20261019.tar.gz.sha256
tar -xzf jht-market-task-return-20261019.tar.gz
cd jht-market-task-return-20261019
bash apply.sh
```

安装脚本校验旧文件版本、备份代码、更新并重启 `jht-app`，随后检查健康和集市入口。版本不匹配会停止。包内没有 `.env`、用户数据库、素材或密钥；不会改动这些文件。安装需要重启应用，建议等当前图片、音频生成结束后执行。已有供应商任务 ID 的视频由原账号重新进入集市后继续查询。

回滚：

```bash
cd /tmp/jht-market-task-return-20261019
bash apply.sh rollback
```

备份位于容器 `/app/.deployment-patches/market-task-return-1/originals.json`。补丁保存在当前容器内；以后从本项目源码重新构建 Docker 镜像也包含修复。删除容器后用旧镜像重建会回到旧代码。

## 验证

更新后重新打开集市里的建绘通。开始视频生成，切换到集市另一个上方页签，再回建绘通，应自动打开原对话、显示“生成中”，最后更新为原任务结果。

本地验证使用临时数据库和模拟供应商，不调用真实收费模型：

- 真实 Chrome 销毁、重建跨来源 iframe；HTTP 和 HTTPS 反向代理场景下恢复原任务，供应商提交次数保持一次。
- 离开期间完成、浏览器恢复记录清空、明确打开首页、切换账号。
- 新集市会话恢复旧视频任务；旧的失败退避被新有效会话解除；恢复期间阻止同一对话再次提交。
- SQLite 与独立 PostgreSQL 测试 schema 的任务发现、图片/音频状态、已删除记录及用户隔离。
- 更新包安装、重复安装、回滚、版本冲突和后续文件修改保护。
