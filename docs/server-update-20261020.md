# 建绘通累计更新补丁（2026-10-20）

补丁版本：`media-update-20261020-1`。沿用之前的 `apply.sh` 安装方式，适用于现有 `jht-app` 容器，支持从 `video-reliability-1`、`market-task-return-1`、`media-library-styles-1` 或 `media-library-styles-2`（R2）直接升级。此前的集市登录和 HTTPS 代理修复须已安装，无需逐个补装中间版本。

此包使用最新本地工作区的运行代码，包含尚未提交 Git 的修改。包内 `UPDATE-MANIFEST.json` 记录基准提交、工作区快照及每个更新文件的 SHA-256；基准提交不代表这些新修改已提交或推送。

- 视频预览加入加载、加载较慢及失败重试状态，保持竖屏、横屏和方形视频的正确比例。

## 上传和安装

将下面两个文件上传至服务器 `/tmp`：

- `jht-media-update-20261020.tar.gz`
- `jht-media-update-20261020.tar.gz.sha256`

安装会重启 `jht-app`。等当前生成任务结束后，在服务器逐条执行：

```bash
cd /tmp
sha256sum -c jht-media-update-20261020.tar.gz.sha256
tar -xzf jht-media-update-20261020.tar.gz
cd /tmp/jht-media-update-20261020
bash apply.sh
```

出现校验失败或版本不匹配时停止，不继续后续步骤。脚本使用之前部署环境的 `jht-docker` 命令，先核对包内文件和服务器旧代码，备份后更新并重启容器，再检查服务健康、集市入口、静态资源、运行文件及风格参考图。重复安装会报告 `ALREADY APPLIED`；未知代码版本会被拒绝，不覆盖后续修改。

更新成功后重新打开集市中的建绘通，必要时使用 `Ctrl+F5` 刷新。此前缓存失败的视频可点击「重试下载」重新下载原文件，不会重新发起生成；原链接已过期或服务器网络仍无法访问时，需要根据显示的具体错误继续处理。

## 回滚

```bash
cd /tmp/jht-media-update-20261020
bash apply.sh rollback
```

备份位于容器 `/app/.deployment-patches/media-update-20261020-1/originals.json`。回滚恢复安装前的代码，保留业务数据；发现后续代码修改时会停止，避免覆盖新修改。若重启后的检查失败，可先查看 `jht-docker logs --tail 80 jht-app`，再决定是否回滚。

补丁保存在当前容器中，重启同一容器仍有效。删除容器并以旧镜像重建会恢复旧代码，需要重新安装补丁，或用最新源码构建镜像。
