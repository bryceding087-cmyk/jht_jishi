# 提示词合成

输入为分镜版本、真实参考素材、模型方案、用户保留的手工提示词和通用风格约束。使用[提示词模板](../../templates/shot-prompt.md)。

## 执行

1. 确认脚本节点已经保存，用户后续手工修改已合并。只处理未完成或受修改影响的镜头。
2. 调用 `jht_script_generate` 的 `prompts` 动作；单镜修订时传 `scene_index`。该接口会保存结果，完成后采用返回的新项目版本。
3. 分别核对 `storyboard_prompt` 与 `motion_prompt`：前者说明主体、场景、构图、光线与风格，后者说明动作顺序、速度、运镜和转场。保留中文及必要专有名词。
4. 将必要的跨镜头约束并入用户可见字段。当前脚本服务按两项原文合并最终提示词，不能在提交视频时另追加用户看不到的尾注，否则审核输入与实际输入不一致。
5. 对白按模型实际支持方式传入，正式音频与字幕继续独立关联。精确文字、Logo 与字幕由后期处理，不指望视频模型画对文字。
6. 校验合并后的提示词非空、当前接口最多 4000 字符、画面与动作不冲突、素材与人物一致。需要修改时用 `jht_script_save` 保存可见字段。
7. 请求主控通过 `canvas-management` 取得实际画布输入；由宿主形成 `input_digest`，随采用的提示词和版本保存，不自行构造哈希值。

## 返回与检查

按[统一协议](../../contracts/runtime.md)返回 `PromptSet` 和提示词检查。主控应在 G3 中展示这些实际输入，并在提交前复核它们仍对应当前分镜和画布。

接口失败保留旧提示词；用户已修改的内容不被后台迟到结果覆盖。新模型需要不同提示词时创建新版本并标明影响镜头。
