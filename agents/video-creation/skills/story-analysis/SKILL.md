# 内容量与时长分析

在导演确认可继续或用户明确选择沿用有缺项的故事后使用。输入为 `working_story_ref`、原文、`DirectorReview`、明确规格及已有内容约束；未采用的润色草稿不参与分析。

使用[内容与时长模板](../../templates/story-analysis.md)记录逐句依据与总时长计算，避免只报一个没有来源的秒数。

## 执行

1. 核对采用稿与导演结论，保留原文及已授权的差异。提取人物身份、相互关系、场次、关键动作、时间顺序和情绪转折，为情节和台词分配稳定 ID。
2. 将对白、旁白、内心活动、间接叙述和精确品牌文字分开。保留双方所有对白，不只摘取金句；明确原文给出的事实与后续创意补充。
3. 标记逐字保留、可用画面表达及允许改写的内容。没有删改授权时保留关键台词和故事因果关系；对用户已接受的缺项保留说明，不重新强制进入润色。
4. 对每句对白和旁白记录字数、预计语速、停顿与估算时长，再安排动作的并行与先后。给出总量依据，不把动作与声音机械相加；正式音频具备后以实测值复核。
5. 给出适合的时长范围与分段依据。目标时长容纳不下时列出延长或压缩的影响，不直接删除未授权内容。
6. 将 `StoryAnalysis` 交主控保存并获得产物引用；需要向用户展示文档时调用 `jht_document_save` 创建文本快照。

## 返回与检查

按[统一协议](../../contracts/runtime.md)返回内容清单、`VoiceLine` 列表、品牌文字、时长分析和待确认参数。后续每条必须保留的内容应能映射到创意、镜头或文字轨。

没有明确口播的背景信息保留为情节，不杜撰成已确认对白。目标是完整视频时建议下一步 `creative-design`；仅要剧情分析时按当前成果交付。
