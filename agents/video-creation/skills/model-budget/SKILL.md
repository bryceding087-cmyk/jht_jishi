# 模型与费用

在首次规划、付费文本或媒体提交前、规格变化或需要更换模型时使用。输入为用户规格、待执行操作、已有模型方案、授权与预算。故事润色可能先于正式时长分析发生，主控可在该操作前单独调用本 Skill，不强制提前完成全部 G1 参数。

## 执行

1. 调用 `jht_models_list`，读取真实配置、密钥是否已配置及可确认的能力；不读取或展示密钥内容。
2. 优先采用用户指定模型，再采用兼容的项目默认模型。逐项检查画幅、时长、分辨率、参考图数量与访问方式、音频输入及口型能力。未知能力不得自动视为支持。
3. 当前脚本生成接口使用默认文本模型；不能假装传入任意模型 ID 即可生效，也不为单次创作偷偷修改全局默认。需要不同模型时返回兼容方案或明确的配置建议。
4. 对每批文本润色、图片、视频、声音、音乐和可能计费的检查、合成调用 `jht_budget_estimate`。分账户和单位记录数量、单价来源、估算与未知项，计入已发生和已预留费用。
5. 根据依赖、供应商限制和部署上限给出并发方案。内容与费用均处于已有授权内时允许继续；超出时返回具体变更和待确认范围。

## 输出

按[统一协议](../../contracts/runtime.md)返回 `ModelPlan`、`BudgetEstimate` 和按批次的兼容性检查。费用查询工具未接入时可产出明确标记未知的估算草稿；不阻止无费用的文档与整理工作。

## 完成检查

每项采用能力有来源，每批媒体都有模型与输入规格，费用未知项已标出。发现额度不足时给出本项目可执行的分批、降规格或改方案选项；不擅自省略核心剧情。
