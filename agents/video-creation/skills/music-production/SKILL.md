# 配乐与声音氛围

分镜确认后、视频片段生成前默认调用本 Skill 制作整片 BGM。输入为已采用的 `Storyboard`、`PlannedTimeline`、情绪结构、对白区间和用户偏好。后期再以实际 `Timeline` 对齐。使用[配乐模板](../../templates/music-brief.md)。

操作 `generate_full_bgm` 负责提前生成整片音乐；`align_to_timeline` 负责将已生成的音乐适配实际成片长度。计划版制作不要求已有视频文件，也不调用实际片段检查来阻塞 BGM。

## 执行

1. 用 `jht_assets_search` 查找适合的用户音频和已有音乐，检查长度、风格与当前对白安排。用户指定不用音乐时返回不适用。
2. 确认所需前置正式配音已完成时长复核；有冲突时先修订分镜和计划时间线，避免按过期时长生成 BGM。原生对白或后期补录使用明确标注的估算。从 `PlannedTimeline` 建立整片绝对时间节拍表：起止秒、情绪、能量、乐器、节奏变化、对白和留白，标记 `basis_kind=planned` 和分镜版本。
3. 对有对白或旁白的项目优先设计纯音乐，给语言表达留空间；用户要求歌曲时按其意图设计，检查歌词与对白的关系。
4. 按实际音乐工具支持的时长和结构标签形成提示词。交主控保存 `MusicPlan` 后，用 `jht_music_generate` 提交该版本。
5. 用 `jht_audio_query` 取得实际 BGM 资产，交 `quality-review` 检查可用性、意外人声及长度，交画布模块保存音频节点。音乐已就绪或已记录用户的无配乐/顺序例外后，主控才进入默认视频批次。
6. `align_to_timeline` 接收原 BGM 及实测时间线，记录 `basis_kind=actual`；优先以裁切、合适循环、淡入淡出及压低对白区间音量完成适配。返回给剪辑模块的是明确编辑安排，不要求再次调用音乐生成。
7. 原音乐确实无法适配时说明需要重制的区间和费用，按已有授权执行或交主控确认。必要环境音可复用素材，缺少音效能力则单独报告，不把音乐接口当作通用音效生成器。

## 返回与检查

按[统一协议](../../contracts/runtime.md)返回 `MusicPlan`、音乐资产和针对当前时间线的混音建议。配乐结果不修改对白原文或视频镜头顺序。

若音乐服务缺失可复用合适音频；没有可用音乐且配乐为必需时，返回受阻原因和已有成果。用户可选择补充音乐、取消配乐或明确改为先做视频；未选择前不静默改变默认制作顺序。
