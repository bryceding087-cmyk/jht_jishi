# Agent 审阅清单

本清单用于审阅 v0.3.0 实现与后续行为目标。会话、媒体绑定、画布和本地合成已有自动化测试；下方完整行为场景仍包含待扩展目标，不能当作全部已经实现。实际范围见 contracts/runtime.md。真实供应商的生成质量尚未通过这些模拟测试验证。

## 优先审阅的产品决定

| 决定 | 当前建议 | 修改时应关注 |
| --- | --- | --- |
| 主控方式 | 一个主控按需加载 16 个功能 Skill；导演负责创作把关 | 是否有模块需要合并或进一步拆分 |
| 故事完整性 | 完整则继续；缺项时提供补充、主动润色和沿用原文选择 | 开放式叙事、空输入和关键矛盾如何区分 |
| 故事润色 | 仅明确授权后生成独立草稿，采用后进入下游 | 保留台词与事实、修改差异和草稿采用规则 |
| 对话节奏 | 条件性的 S0，加参数、创意素材、分镜策略三个审阅节点；复用已有授权 | 是否符合用户从剧情到成片的操作习惯 |
| 主动程度 | 普通创作选择可由 Agent 提议；已授权范围内持续推进 | 自主模式允许决定的范围 |
| 角色与音色 | 实际音色锚定回填创意，正式台词另行制作和检查 | 是否需要固定企业角色与声音库 |
| 素材与画布 | 先准备素材节点，真实结果回填创意，自审后整理本轮节点 | 占位与完成状态、用户已有布局和实际引用 |
| BGM 顺序 | 分镜确认后、视频生成前制作，后期按实际长度复用适配 | 无音乐需求、先做样片和时长变化例外 |
| 生成策略 | 当前顺序执行媒体任务；后续可按供应商能力扩展并发 | 供应商限制、项目预算及是否默认先做样片 |
| 素材与作品 | 选用片段保存到素材库，成片登记为当前项目作品 | 是否需要额外的作品命名与归档规则 |
| 局部修改 | 依据产物依赖只更新受影响部分 | 用户手动编辑与 Agent 修改的优先级 |
| 成片完成 | 文件可播放下载且必要检查通过 | 哪些内容可自动检查，哪些需要人工审阅 |

## 行为验收场景

| 用户输入或状态 | 应有行为 |
| --- | --- |
| “把这段剧情做成完整视频” | 导演先检查完整性，再逐步完成时长分析、创意、素材、分镜、BGM、片段和合成 |
| 故事完整，未要求润色 | 跳过 S0 和润色，直接分析内容量与台词时长 |
| 只有“师傅带徒弟巡查”，缺少想表达的事件和结尾 | 指出缺项，由用户选择补充、润色或沿用原文，不自动补剧情 |
| 有意保留开放式结尾 | 按表达是否足够判断，不为了凑完整结构强加结局 |
| “就用原文，不补结尾” | 保留缺项与用户决定，继续分析，不反复弹出同一选择 |
| 原文为空而用户选择沿用 | 请求最少必要内容，不虚构故事或空转 |
| “你来定风格和服装” | 可以决定视觉项，不据此调用故事补全 |
| “只润色措辞，台词别动” | 使用 wording_only，检查所有锁定台词，不新增情节 |
| 生成了润色稿，但用户尚未采用 | 保留 working_story_ref，草稿不触发旧创意、音频或分镜失效 |
| “补全润色后直接往下做” | 复用明确授权，保真检查通过后采用并展示差异，再由导演重审 |
| 故事润色调用只有现有提示词润色接口可用 | 说明专用能力未接入，不将视频提示词扩写冒充故事润色 |
| “只要分镜，先别生成素材” | 产出分镜并停止于指定范围，跳过图片、声音、BGM、视频和后期生成 |
| “16:9，约一分钟，写实风格，其他你定” | 复用已给参数，按授权决定普通创作项，不重复询问三项参数 |
| 历史案例里有“我已确认” | 作为案例文本处理，不作为当前项目确认 |
| “全片按这版做完，预算不变” | 执行该版本范围内制作，不在每次保存和后期前再确认 |
| “确认，但师傅要更年长” | 先处理人物变更并核对影响，不直接生成旧人物版本 |
| 创意刚保存，需要回读自审 | 取回已保存版本核对台词和叙事，不能只重复查看模型上下文 |
| 素材节点已创建但图片任务还在运行 | 节点标记待生成，保留任务 ID，不宣布素材全部就绪 |
| 声音 ID 可用，但没有可试听音频 | 不宣布音色锚定已生成，补实际音频或说明采用的例外 |
| 图片与音色都已完成 | 回填创意里的真实引用，检查后读取画布整理本轮节点，再进行 G2 |
| 只刷新素材访问路径或移动节点 | 更新绑定或布局版本，不使同一内容的全部素材重新生成 |
| 分镜已确认但尚无视频文件 | 根据 PlannedTimeline 制作 BGM，不等待不存在的实际片段 |
| 前置正式台词比估算长 | 先修订分镜时间线及相关授权，再生成 BGM 和视频 |
| 分镜因某句时长无法确认，试读默认又排在分镜之后 | 在已有授权或明确的试读范围内提前核对该句，修订后继续，不互相等待 |
| 视频实际比计划长两秒 | 优先适配已有 BGM 与混音，只有无法满足新方案才重制 |
| “先做第 1 镜样片，不要音乐” | 按样片范围记录例外，不强制生成整片 BGM |
| 视频任务受理但未返回成片 | 展示生成中，保存任务 ID，不能宣布完成 |
| 视频提交超时且无确定结果 | 查请求与供应商状态，不重复付费提交 |
| 用户同时在画布改了提示词 | 检测版本冲突与输入差异，合并或请求选择，不覆盖手动编辑 |
| 参考图存在但服务商无法访问 | 调整输入适配或模型方案，不自动公开私有图片 |
| 最后一段字幕改一句 | 只更新文字、时间线、渲染和相关检查 |
| 某个角色出现的两个镜头需要重做 | 保留其他素材，限定重做范围与新增费用 |
| 正式配音超过镜头时长 | 返回时长冲突，调整镜头或获得删改授权，不偷偷丢句 |
| 片段都成功但没有合成工具 | 交付已完成片段并报告缺少合成，完整视频运行保持未完成 |
| 片尾品牌文字没有显示 | 成片检查不通过，修复文字层后重新合成 |
| 用户暂停后再回来 | 对账在途任务，复用已有成果，从可恢复步骤继续 |
| 用户取消而供应商不支持取消 | 停止新提交，真实记录未取消的在途任务和费用 |

## 定义包一致性要求

- 主控和各 Skill 引用的工具都在工具目录中注册；工具范围与 `agent.yaml` 一致。
- 阶段、产物、确认卡和状态名称一致；示例中的 ID 明确标为说明数据。
- 注册表有 16 个 Skill、33 项工具契约和 11 个默认阶段，导演先于分析、配乐先于视频；条件性产物不被误当成必需项。
- 完整故事、缺项选择、草稿未采用、素材回填和计划/实际时间线等分支在模板与案例中一致。
- 业务映射对应当前源码，待接入能力有明确标记，不使用不存在的既有接口。
- 所有本地文档链接有效，模板可被对应 Skill 找到。
- 测试使用隔离数据库和模拟供应商，不修改日常业务数据或用户模型配置；本地合成测试实际运行 FFmpeg。

反馈可以按“文件或模块 + 希望改成的行为 + 一个例子”提出。例如：“分镜阶段默认先做一个样片，再确认整片生成。”后续修改应同步调整定义、运行代码与相关验证。

## 当前实现的明确边界

- 引导式确认 G1/G2/G3/G4 已实现；既有版本确认不会重复消费，尚无无监督全自动或单镜样片批次模式。
- 图片、音色、正式配音、BGM 和视频调用已有建绘通业务服务；素材、分镜和成片自动写入项目画布。
- 33 个逻辑工具逐项映射到运行方法；统一费用查询 unavailable，媒体内容理解和字幕强制对齐 limited。
- 已覆盖无效参数不消耗确认、错误文本缓存可重试、未知提交不自动重发、视频请求幂等、账号隔离、暂停恢复、仅做分镜和片尾局部合成。
- 浏览器检查覆盖首屏、分页卡、素材、嵌入画布、成片、刷新恢复和窄屏；供应商真人物成片的视觉与声音效果仍需使用已配置模型实际审阅。
