# 影像配方与例子

## 角色与场景

角色图的价值是可复用的身份参考。给出脸部/体态、发型、服饰层次、材料、主色、配饰和中性神态，完整显示轮廓。奇幻角色只有剧本指定时才增加鳞片、犄角或发光眼，不因“蛇妖”默认露出蛇尾。

人物造型示例（原创建议，不是剧本事实）：石瑞，24岁成年男性书生，瘦长脸、平直眉、黑发束低髻，灰青交领布袍、米色内衫、深褐窄腰带，衣料有细密麻纹与磨旧袖口。姿态克制，双手自然垂落，正面全身平视，素净中性背景、均匀柔光。将脸部、发髻、交领层次与腰带固定为身份锚点。若剧本没有上述衣色，记录在美术建议里，后续场景复用。

同一场景的设计应能画出平面关系。例：乌岫山洞，入口位于画面左后方，右侧是低矮石榻，后壁石台依次摆五盏灯，中间保留两人并行通道，近景浅水洼映出灯光。岩壁不规则湿痕，灯是可见实用光源。日/夜改变洞口入射光而不改变灯台与石榻相对位置。灯的“亮了几盏”是剧情状态，镜头单独明确，不能所有集都默认全亮。

关键道具示例：同一支细竹哨，哑光淡褐竹节、吹口有磨损、短棉绳系在末端，单一物件置于中性背景，以斜侧近景展示吹口与系绳。独特刻痕若原文未提及，只能列为设计建议；不擅加可揭露谜底的文字。

## 一个视频片段的可执行信息

镜头先回答：摄影机在哪里、主体在哪里、动作开始时是什么状态、只发生哪件事、结束时留下什么状态。随后确定景别、主运镜、光源、声音。

例（有已确认角色、场景参考时）：

> 图片1用于石瑞的脸部与衣服，图片2用于小哲的脸部与衣服，图片3用于洞内空间。平视中近景，两人隔着石桌相对。石瑞缓慢伸出右手，手掌朝上，在小哲指尖前停住；小哲看向他的手，随后将左手轻放在他掌心。镜头固定，保持石桌、洞口和灯台的位置，侧后方灯光在袖口形成细窄暖边。仅衣料摩擦和洞中滴水声，无新增对白，无背景音乐。人物形象沿用参考，双手的接触关系清楚，动作结束时两人的手停留在桌边。

这段按“一次伸手—接触”构成单一动作，不把牵手、拥抱、下山、逛灯市塞进六秒。若原文只有“递出手”没有牵手成功，不自行添加结果。

同一镜头的图生视频版本：

> 保持首帧的人物身份、服装、桌面与灯光方向。画面左侧男子缓慢伸出右手，掌心向上，在右侧女子指尖前停住；女子将左手轻放上去，动作轻缓连贯。摄影机固定，结束时两人的手停留在桌边。仅保留衣料摩擦与滴水声，无新增对白。

首帧则写“男子右手仍在自己身侧，女子双手收在桌沿”，尾帧写“女子左手轻放男子右掌，双手停在桌边”。静态帧不要把两种状态叠成重影。

## 特殊场景处理

- 对话：人物名＋原句＋可见表情/停顿；镜头包含多少台词，应按自然语速留时间。超过片段预算就拆成反打或续镜，不删掉重要台词。音色记录可以后期制作，不虚构已上传声音样本。
- 动作戏：用起势、接触、后果分镜；固定运动方向与受力对象。保持武松打虎等原有动作强度，不一律改成微动作。快速肢体交错、穿插遮挡、物体破碎列风险，给出清晰首尾帧和剪辑承接。
- 志怪：区分实体、影子、倒影、记忆残像与幻象。规则性物体数量必须明确，变化只能由剧本对应行动触发。
- 群像：人数和空间关系明确，主角、背景群众分层；复杂群体互动先做构图帧。不要给每位无特写群众做独立角色卡。
- 产品/文字：忠实保留文字需求；小字、标志与证据文书若要求精确，列后期叠加或指定参考图，不许用“无任何文字”把剧情证物抹掉。

## 质量检验

提示词检查与实际画面验收分开。实际生成后检查角色主参考及多角度身份、场景反打方位、首中尾三时刻的动作/手/道具/衣纹/灯光，必要时短片先试再铺开。调整具体缺陷，不只添加“8K、顶级、极致细节”。
