# 小说、剧本与分镜衔接：建绘通适配

根据用户的实际输入区分小说改编、剧本创作和已有剧本拆镜。当前已有剧本时直接解析场次、画面描述、对白、动作和情绪，不重写原故事。每段视听信息映射到对应镜头，保留场次和真实原文行号。

角色名称、身份与变体稳定映射到资产登记表；场景和道具同样复用。景别服务叙事：空间关系用全景或中景，对话和反应用近景，关键证物用细节镜头，追逐明确运动方向。不要把这些建议当成覆盖已定分镜的强制模板。

图片与视频提示词分工：图片表达空间、人物、静态姿势、光影与机位；以该图为首帧的视频重点表达角色动作和摄影机运动。纯文本视频才需要完整外观与环境。图片中不叠加多个动作阶段，视频中不遗漏指定结束状态。

写作与拆镜后检查每场原文、说话者、动作顺序、道具连续性和镜头衔接。保持用户选定的语言与画风，不默认改为英文或动漫。可交付的分镜描述不等于图片已生成或成片已完成。
