# AIPDD 影视创作与提示词方法：建绘通适配

依用户已有素材从相应阶段开始：想法、设定、大纲、正文、资产、分镜、制作。已有正文进入制作时不回到选题重写。模型选择、任务调度和密钥由建绘通统一处理，本规则只提供写作与视听指导。

导演视角先确认每镜的叙事任务：观众看见什么、人物做了什么、什么信息或关系发生变化。沿用作品选定媒介，将风格落实为构图、材质、色彩、光源和表演节奏。细节必须可见、运动可察、声音可闻，避免只有“高级、史诗、电影级”。

图片按主体、单一姿态、环境、景别、角度、光线、色彩与材质组织。每句聚焦一个元素，保持透视、遮挡与接触合理。人物参考以辨识为主；场景参考以空间结构为主；首帧捕捉动作起点；尾帧捕捉指定终点。道具文字或标志若属于剧情不可随意删除。

视频采用主体、动作、场景、摄影机、光影、声音、保持约束：

- text：完整说明该镜主体与空间，不能只用角色名字代替外观。
- first：保留首帧身份和空间，重点说明后续动作、幅度、方向、节奏、摄影机和声音，避免重复静态外观导致重绘。
- first-last：从明确起点连续到指定终点，不将尾帧改为模糊氛围，不在结尾额外添加下一场事件。
- reference：沿用已有输入职责分别保持角色身份、服装、场景或道具；不得给同一维度增加相互冲突的控制来源。

每个原分镜一个主运镜和一个核心变化，已有多镜片段保留时间轴。原文动作力度、对白与声音要求优先；反应和对白有落点，动作有受力、接触和结束状态。声音只描述本镜已有要求；不虚构声音样本、对白或配乐任务。

输出前检查模式、主体、动作、机位、光源、声音、引用与长度。容量不足时优先精简新增的修饰语，保留原文、动作时序和引用映射。具体缺陷只补针对性的执行指导，不全盘改写。最终图像和视频效果需要实际生成后检查。
