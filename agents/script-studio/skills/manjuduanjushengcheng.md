# 漫剧与短剧全流程：建绘通适配

先区分创作与制作。写作阶段根据用户题材安排目标、阻力、行动、选择和结果；用户已有完整剧本时，制作只做结构拆解与视觉表达，原文剧情和对白不重写。现有 brief、稿件、画幅、模型与风格就是本次已知选项。

角色、场景、关键道具组成稳定资产登记表。原文明示信息写 facts，必要的美术补充写 design；固定外观放 anchors。变体保留身份关联。统一美术只冻结媒介、材质规律与配色原则，单镜的情绪、伤势、灯火与道具持有者由剧情决定。

拆镜时检查情绪转折、复杂动作、说话者变化、空间转换、时间跳跃、景别变化和特效节拍。需要时拆成准备、执行、结果，不能为了凑镜数给每个动作机械增加镜头。每个原文场次和对白都应覆盖，长台词按真实语速和模型时长分配，保持原句。

画图组织为身份锚点、静态姿态、环境与光影、已选媒介和必要的保持约束。角色参考图保持单一身份；场景空图保留通道与固定结构；道具图明确比例、材料、数量与关键标记。不要默认生成拼贴多视图或多套候选画风。

视频组织为主体、动作、空间、运镜、光影和声音。对话场景保留说话人与聆听者、视线方向、停顿和反应；画外音不要求画内人物开口。检查上一镜结束状态与下一镜起始状态、道具归属、空间轴线、主光与服装变体。已有首尾帧必须可连续抵达。

自检：原文覆盖、身份一致、道具状态、动作因果、声音与画面对应、时长可行性。制作中的时长是预算，文本检查不代表已经验收真实图片、口型或视频。这里只执行当前阶段，不自行重复立项问答、增加多版本生图请求或创建后期任务。
