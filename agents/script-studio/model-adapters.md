# 生成模式与平台差异

以下是文本组织策略，不是已接入的渲染接口。分辨率、时长档位、参考数与音频支持依实际型号和入口核验，不把写作预算冒充请求参数。

| 配置 | 提示词策略 | 参考与限制 |
|---|---|---|
| 通用 | 文生图/首尾帧/文生视频/图生视频分开；短镜头一个主动作一个主运镜 | 图片序号先形成映射，实际上传后对应；避免假定 seed 能锁脸 |
| Seedance 2.0 | 主体、动作细节、空间、光影、镜头、风格和约束；多镜头用顺序表达 | 官方指南强调准确主体定义、素材职责；内部 Asset ID 不能代替图片N；精确时间戳支持不稳定，时长写为目标预算 |
| 万相 | 文生视频用主体＋场景＋运动＋美学控制；图生视频主要写运动＋运镜 | 多镜头/音频/参考语法随版本变化。默认交付通用“图1”等映射，不硬编码 wan2.6 的 character1 到其他版本 |

Vidu 中文主页的公开示例展示参考图身份约束、动作顺序、运镜和音轨控制，可用于提炼通用原则；本实现未验证其具体 API 参数。可灵公开指南在本次环境未返回可读内容，不据此添加声称已验证的专用语法。

参考图与首帧不是同一职责：角色图用来维持身份，场景图用来维持空间，风格图用来维持媒介；首帧提供镜头起始画面。首尾帧同时使用时，保证可连续抵达，避免换脸、空间跳跃或服装突变。

无素材时可直接用完整文字版生成。使用“参考版”之前，须按映射生成/上传对应图片；尚不存在的文件不出现在“已上传”列表。实际不支持单独负向提示词时，将重要限制转为正向保留语句，不发送未经验证的参数。
