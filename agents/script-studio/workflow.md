# 任务工作流

本工作流由公开界面和可观察交互启发，再针对个人创作独立实现。已观察到创意技能先整理已指定信息与推荐补充，并提供确认卡；剧本医生和局部小说拆解可分别生成独立报告。它们不证明有三套模型、三个后台 Agent，或固定的私有提示词。

## A. 接收输入并选择下一产物

先在已有对话和素材中找可用版本，再判断用户要的是创意、设定、大纲、正文、分析还是修订。优先执行明确动词：“诊断、拆解、续写、改结局”优先于“仙侠、年代、古装”等题材词。

| 起点 | 本次合理行为 | 避免的偏离 |
|---|---|---|
| 一句话创意 | 梳理已指定，补最少缺口，给主方案 | 一次抛十个问题让用户重填表 |
| 完整设定，要求大纲 | 检查设定冲突后直接排集 | 重写题材和人物，重新让用户确认同一设定 |
| 有前几集，要求续写 | 提取当前状态与未回收伏笔，再写后续 | 每集重复人物介绍，忘掉已公开信息 |
| 一段小说，要求拆解 | 按当前片段范围给独立报告 | 编造后文或直接将小说改写成全剧 |
| 现稿，要求诊断 | 有证据地定位问题与修复建议 | 为展示能力替换整部故事 |
| 明确要整套剧本 | 设置推荐缺省值，连续完成设定、大纲、正文和检查 | 每阶段无条件暂停询问 |

多个任务相连时按依赖执行，例如“拆解并改编”先分析原文再创造新增情节；“诊断并润色”先辨清因果问题和表述问题，再修改要求范围。

## B. 收敛创意

在初次创意回应中使用以下最小信息架构，已有项目简写或略过：

**已指定**：只写用户明确提供的类型、人物、结局、禁用项等。

**推荐补充**：用一句话分别补受众或观看动机、核心梗、类型与情绪走向、集数、时长、制作规模中真正缺失的项目。默认建议 10 集、每集 90—120 秒；二者均可调整，时长为本地写作建议，不归因于小云雀。

**下一步**：说明将生成哪项产物。探索模式可以给 2—3 个方案或确认选项；完整执行模式写明所采用的假设后继续。

选项要有实际取舍，例如“女主以公开证据赢回店铺 / 以谈判换取共同经营 / 放弃旧店带走工艺重新开业”。“更好看/更精彩/更抓人”不构成不同方案。

不要用默认值覆盖用户数字；用户已给 3 集，即使题材模块中另有建议，也按 3 集。用户已给 BE，不把它改成 HE 来提高所谓商业性。

## C. 建立故事设定

设定应回答六个问题：

1. 谁想得到什么，为什么现在必须行动？
2. 谁或什么持续阻止他/她，阻止者要什么？
3. 主角有什么能力或资源，使用它的代价是什么？
4. 什么规则限制了“轻易解决问题”的路径？
5. 主角必须做出哪项有代价的最终选择？
6. 结局如何兑现主线和情绪承诺？

阅读当前题材模块，将其独有机制嵌入上述因果。仙侠的能力代价、年代家庭的生计资源、古装爱情的信任选择都应在关键事件中被使用；不只出现在背景介绍中。

角色和场景数量按用户预算。未给预算时，给符合集数的精简建议，不强制所有项目固定 4 人 3 场。新增关键角色需承担独立叙事功能；不临时出现万能救场人物。

## D. 从设定排成分集大纲

先确定开局困境、阶段性转折、最终选择和结局，再分配到用户指定集数。每集一个主要行动目标，事件有变化，不要求机械套用同一集号公式。

每集填写：当前状态、目标、阻力、主角行动/选择、结果、观众新增信息与收尾。中间集再明确钩子和下一集必须承接的事实；最终集用闭环、情绪兑现或余韵收尾，无须额外悬念。若一集结束后人物关系、资源、知识或危险都没改变，检查是否可合并或重写。

安排三种跨集依赖：

- 因果依赖：第 3 集解决办法所用资源是否已经存在？
- 信息依赖：谁在第 2 集知道真相，谁仍被蒙在鼓里？
- 情绪依赖：信任、失望、和解是否各有行动依据？

提前为中间集的结尾钩子安排兑现位置。不能只把每集最后一句都写成“真相原来另有其人”，再不断换反派。最终集没有悬念不构成缺陷；核对的是是否兑现了本剧承诺。

## E. 写成正文

正文忠实落实大纲，同时允许不改变正典的表演细节。每场应有触发、目标、对抗和变化；两个场次若重复同一信息，优先压缩。

对白表达当下人物意图，避免让角色替作者讲全套背景。隐瞒、试探、讨价还价、拒绝、承诺比抽象情绪标签更有戏。语气括号只在帮助表演时使用；不每句都加情绪说明。

90—120 秒只作起始写作预算。估计时考虑对白朗读、停顿、动作和转场；不能仅凭字数保证成片长度，也不能宣称实测过。用户要求严格时长时，提供可删减段与节拍预算。

连续写多集时，每完成一集更新状态，再进入下一集。默认交付正文，不在每集后追加大段创作解释。总览和状态差异可以集中到文档附录或最终简报。

## F. 质量检查与反馈循环

设定、因果、正文的问题分别回到对应层级：

- 人物动机不成立：修设定，再更新相关大纲与场次。
- 中段无推进：修大纲，再重写对应场次。
- 台词冗余：局部修正文，不改变全季设定。
- 知识、道具、能力规则冲突：依据当前有效版本修正文和状态台账。

对已授权范围内、没有偏好分歧的缺陷直接修复。遇到“主角必须留在故乡”与“结尾必须永久定居国外”这类实质冲突，明确说明两者无法同时满足，并给至多 3 个具体处理选项。

## G. 到哪里结束

以用户要求的产物和范围结束，不按固定流程多做一级：创意请求可止于方案，诊断请求止于报告，拆解请求止于分析，完整剧本请求完成正文与必要修订。最后说明产物位置或直接展示内容；有未完成范围时明确标示。
